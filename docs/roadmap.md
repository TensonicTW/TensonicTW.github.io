# 建置階段

## 第一階段：可上線骨架（本 repo 現況）

雙語路由、產品／發表／技術分享三類內容、RSS、sitemap、GitHub Actions 部署、Issue 與 PR 範本。

## 第二階段：內容遷移

將 tensonic.com.tw 既有六大產品分類共約 32 個型號逐步建檔，優先處理主力機種與正在報價的型號。每個型號需備齊：正式規格表、產品照、型錄 PDF。

同時決定與官網的分工：官網保留完整型錄與經銷資訊，本站專責發表、規格說明與技術內容，兩站互相連結。

## 第三階段：功能擴充

- 產品比較表（同分類多型號並列規格）
- 依分類、輸出功率、區域數的篩選
- 下載中心（型錄、說明書、韌體、CAD 圖）
- 全站搜尋（Pagefind，靜態站可用）
- 圖片最佳化（`astro:assets`，改用 WebP 與 srcset）

## 第四階段：社群與導流

- GitHub Discussions 作為技術問答區
- 發表文同步至 LINE 官方帳號與電子報
- Google Search Console 提交 sitemap，追蹤型號關鍵字表現

## 維護

規格異動由產品部提 PR；每季檢查一次外部連結與「待補」欄位；每半年檢視相依套件版本。
